# 第3章 冰河突围，第一批山货进城

冰面在脚下发出细碎的裂响，像有人在耳边不断掰断筷子。陈野不敢回头，只盯着前方那条发白的河道中线狂奔。身后摩托车下了河滩不敢直冲，黄毛几个人改成步追，铁链抽在冰上，炸起一串冰渣。

“站住！把合同交出来，虎哥只要纸，不要你命！”

陈野心里冷笑。上一世他太信这种话，结果被堵在砖窑后边打断肋骨。这辈子他只信自己。

【倒计时：01:37:12】
【提示：前方200米有薄冰区，请向左偏移30步。】

系统提示刚弹出，陈野立刻横切。他刚绕开，右侧冰层就“咔嚓”塌了一块，追得最急的矮个子一脚踩空，半条腿陷进去，吓得鬼叫。黄毛骂了一声“废物”，追势顿时慢了。

陈野借机冲上河堤，抄近路钻进一片杨树林。风雪越下越密，视线只剩十几米。他摸到树后蹲下，压住急喘，听着脚步声从另一侧掠过去。等人声远了，他才沿林带一路摸到镇派出所后门。

门岗见他满身雪泥，先是一愣。陈野把竞标合同和情况简要一说，值班民警当即登记，给合同盖了备案章。

红章落纸的那一刻，系统提示音响起。

【紧急任务完成。】
【奖励：经营点+15；危险感知（初级）。】

陈野长出一口气，可还没等放松，新的现实又压上来：七天内要补齐一万四千六百元尾款，不然合同照样作废。

他裹紧棉袄回到家，刚进院门就看见母亲坐在炕沿抹泪。桌上放着一张欠条，王老三来过，逼她按手印卖地。陈野眼神一冷，把欠条撕成两半。

“妈，这地谁也拿不走。给我五天，我把账先平一截。”

母亲不信，却还是把家里最后一袋玉米面塞给他。陈野提着面袋坐到炕边，摊开笔记本，开始算账：林地最快变现的是榛蘑、松子和黄芪，问题是他没人手、没车、没销路。

【主线任务阶段二提示：完成“首次勘林并形成销售闭环”。】
【建议：优先锁定高周转山货，避开重资产投入。】

第二天清晨，陈野背上麻袋进山。北坡林地雪深过膝，走一步陷半步。他凭着上一世记忆和系统“市场嗅觉”，在背阴坡找到一片被雪埋住的榛蘑干货点，又在沟口挖出成色不错的黄芪根。忙到下午，他带着两袋货下山，手都冻得没知觉。

可真正难的是卖。

镇上收货贩子见他是生面孔，张口就压价：“榛蘑八块一斤，黄芪十五，爱卖不卖。”

这个价连人工都不够。陈野转身就走，直奔县城副食市场。他记得有家“老关东炖馆”专收山货，老板娘赵桂芬最怕断供。

到店时正赶上晚市，后厨忙得锅铲乱响。赵桂芬见他扛袋进门，皱眉：“小伙子，散户我不收，质量不稳。”

陈野没废话，抓一把榛蘑放进温水，三分钟后蘑香冲出来，后厨几个师傅都探头看。他又掰开黄芪，断面金黄、纹理细密。

“赵姐，你现在进的货掺陈货，炖出来发苦。我这批全是今天山上新出的干货。你先试二十斤，不好我按双倍退。”

赵桂芬被他说中心事，脸色变了变：“你咋知道我货苦？”

陈野笑笑：“做这行，鼻子得灵。你要是今天不断货，明晚团餐大单还能接。”

这句话直接打中她痛点。赵桂芬当场拍板：榛蘑二十三一斤，黄芪三十八一斤，先收六十斤，现金结算。第一单净赚一千八百多。

陈野揣着钱走出饭店时，夜色像墨一样沉。他没回家，直接去火车站旁的小旅馆敲门，找到跑长途的老同学孙大海。

“海子，帮我拉一趟货去市里药材市场，运费我按高价给。以后每周固定两车。”

孙大海本来不信，直到看到他桌上摊开的现金，眼睛都直了：“你小子这是在哪挖金子？”

“不是挖金子，是抢时间。”陈野把路线图推过去，“你要愿意跟我干，明年换大车。”

当晚，两人敲定合作。陈野又连夜联系了两个屯里的闲汉做采货工，按件计酬。到第三天，他的“采—运—卖”小闭环终于跑通。

【主线任务阶段二完成。】
【奖励：现金2000元；技能“渠道管理（初级）”。】
【下一阶段：七日内累计净利润破1.5万元。】

看着账户里不断跳动的数字，陈野第一次真切感到，这条路走得通。

但爽不过半小时，麻烦又来了。凌晨一点，孙大海打来电话，声音发抖。

“野子，坏了！咱拉去市里的那车黄芪，在三道岭检查站被扣了。对方说咱手续不全，还说……是刘二虎实名举报的。”

电话那头传来一声闷响，像有人砸了车门。随后一个陌生男声贴着听筒冷冷开口：

“陈野是吧？想要货，明天带两万块来赎。晚一分钟，你那批货就按无主货处理。”

嘟——

电话被挂断。

陈野握着话筒站在黑暗里，指节一点点收紧。他知道这不是普通扣车，这是刘二虎把手伸到市里了。

窗外风雪呼啸，远处传来火车鸣笛，长长一声像警报。

陈野抬头看向夜空，低声说：“行，你想玩大的是吧。那这局，我陪你玩到底。”
